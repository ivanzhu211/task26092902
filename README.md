# task26092902

客服机器人知识库匹配引擎（纯 Go 标准库，进程内存存储，无持久化）。

## 功能

- `kb.Import(entries)`：批量导入（每批 ≤1000），按 id 新增或整条替换；
  任一行不合法则整批不生效，返回全部行级错误（行号、字段、原因）。
- `kb.Delete(ids)`：整批删除，不存在的 id 忽略。
- `kb.Match(text)`：返回得分最高且达到 `max(0.6, threshold)` 的条目
  （id、命中权重和、总权重）；同分取 id 字节序最小者；无达标则未命中。

## 设计要点

- 切分：全角 ASCII 折半角、逐字符小写；Unicode L/M/Nd 最长连续串为词元，
  每个汉字单独成词元。词条与消息共用同一套切分。
- 精确打分：得分 = 命中词条权重和 / 条目总权重，阈值比较全部用整数
  （命中权重 ≥ ⌈max(60, threshold·100)·总权重/100⌉），无浮点误差。
- 前缀过滤倒排索引：每个条目只把"按当前全局词频最稀有、且去掉后剩余
  权重不足以达标"的前缀词条放入索引。达标条目必然命中至少一个前缀词条，
  因此 Match 只需精确验证候选集；含高频词但不可能达标的条目不会被扫描。
  词频统计随每批 Import/Delete 增量更新，词频漂移后导入的条目自动按新
  词频选择前缀。
- 并发：`sync.RWMutex`，Match 与写入可并发，单批写入原子生效。

## 测试

```sh
go test ./...        # 单元 + 差分 + 竞态 + 性能场景
go test -short ./... # 跳过耗时比测试
go test -race ./...  # 竞态检测
```
